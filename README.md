## How to Use

Each skill is a standalone `.md` file you can use with Claude Code, Codex, or any agent that reads custom skills.

**Installation:**
1. Copy the folder of a skill you want to use
2. Place it in your agent's skills directory (e.g., `~/.claude/skills/`)
3. The agent will automatically discover and use it when relevant

**Direct use:**
Open the `SKILL.md` file and follow the step-by-step instructions. Most skills include:
- When to use it
- What you'll need (tools, accounts, data)
- Step-by-step procedure
- Templates and examples
